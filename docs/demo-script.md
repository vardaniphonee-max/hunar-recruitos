# Five-minute demo

## 0:00–0:30 — Frame the product

“Hunar RecruitOS combines all three assignment prompts in one recruiter journey. The purple Demo mode label means no paid search or real phone call is being used.”

Show the Overview: active roles, candidates, funnel, call outcomes, and recent activity.

## 0:30–1:15 — Create the role

Open **Roles**. Explain that the role brief becomes both editable people-search criteria and the structured result schema for the voice workflow. Point out the four screening questions and role-health feedback.

## 1:15–2:10 — Discover and shortlist

Open **Talent search** and run the search. Explain that the application has one Apollo adapter and one contract-compatible demo adapter. Show the explicit Demo data labels, transparent match score, and match reasons. Shortlist Ananya and Rohan.

## 2:10–3:15 — Run the voice workflow

Open **Campaigns**. Review the candidates and screening plan. Launch the demo campaign and emphasize the safety confirmation: no real number or paid API is called. Wait for the simulated states to complete.

Explain that the real adapter uses Hunar's documented `POST /calls/`, callback configuration, polling fallback, and signed/idempotent callbacks.

## 3:15–4:10 — Review the candidate

Open Ananya's result. Show the demo transcript, structured answers, recommendation provenance, and recruiter override. Emphasize that live payloads never receive invented transcript fields and that the automated recommendation is advisory.

## 4:10–4:50 — Attendance blueprint

Open **Attendance blueprint**. Click Capture, Verify, and Reconcile. Explain shared RFID/biometric terminals, feature-phone IVR fallback, rotating site codes, offline sync, anomaly review, and human-approved corrections.

## 4:50–5:00 — Close

“The public demo remains fully reviewable after credentials expire, while the backend includes live Hunar and Apollo adapters with secrets kept server-side.”
